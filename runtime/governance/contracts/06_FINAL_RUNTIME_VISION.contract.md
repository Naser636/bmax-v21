CORE PRINCIPLES

- Réutiliser avant de créer.
- Mesurer avant de modifier.
- Vérifier avant de valider.
- Apprendre après chaque mission.
- Toujours respecter les contrats de gouvernance.

1. Architecture entièrement cartographiée.

3. Décisions fondées sur les données.

SUCCESS CRITERIA

Le Runtime est capable de :

- comprendre son architecture ;
- produire un plan d'action argumenté ;
- apprendre des missions précédentes ;
- réutiliser ses connaissances ;
- proposer des améliorations cohérentes ;
- ne jamais modifier le dépôt sans validation du CTO.

END STATE

capable d'accompagner le CTO dans toutes les
