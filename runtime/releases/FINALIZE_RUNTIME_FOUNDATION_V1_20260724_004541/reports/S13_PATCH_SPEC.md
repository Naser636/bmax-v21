# Sprint 13 - Patch Specification

Mission:

Design ONLY the minimal patch.

No implementation.
No code.
No Git diff.

Answer only:

1. Files to modify.
2. Responsibility of each modified file.
3. Public APIs that remain unchanged.
4. Exact dependency to remove.
5. Exact dependency to introduce.
6. Validation sequence.
7. Rollback strategy.

Rules:
- One patch.
- One responsibility.
- Preserve compatibility.
- No new architecture.
- No assumptions.
- Base every answer on the inspected source files only.
