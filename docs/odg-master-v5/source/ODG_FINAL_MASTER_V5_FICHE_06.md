Five permitted editorial decisions
Every newly proposed concept is classified as exactly one of:
MERGE     = same meaning, authority, lifecycle, inputs, outputs and invariants
NEST      = specialized form under an existing parent principle
PRESERVE  = materially distinct function or artifact
REFERENCE = existing authority is reused without repeating its definition
RETIRE    = duplicate, obsolete, invalid, or superseded
ADD is not a semantic decision. A proposed addition must first pass this classification.
Authority precedence
When definitions overlap or conflict:
CONSTITUTION
→ PERMANENT PRIMITIVE
→ CAPABILITY / OPERATING PATTERN
→ IMPLEMENTATION / WORKGRAPH
Within the same level, the explicitly designated canonical owner controls. Current verified reality controls claims about implementation state. Explicit authority controls over inferred preference.
Contextual projection rule
Cinema, robotics, software engineering, research, economic operations and other Industry Packs may specialize the same general principle without redefining it.
Example:

verification appropriate to the production.

ROBOTICS:

verification appropriate to physical execution.
The domain application adds tests and context; it does not create a second constitutional law.
Loss-prevention rule
Fusion must never remove a unique operational detail merely because its principle is shared. Unique inputs, outputs, constraints, failure modes, proof obligations, transfer limits, economics, provenance and domain tests remain attached to the appropriate specialized form.

SAFE STOP
ABSTAIN / DECLINE
Speed is not progress. Activity is not resolution. Internal agreement is not external proof.
