# Action/Combat Diagnostic — F7 (Phase 2) — 2026-10-24

## Honest finding (the premise of this phase)
**La Porte du Soleil is NOT a martial-combat film.** Its "action" is **environmental peril** (storm crossing,
the time-tides, the canyon of frozen waves, the convergence SIEGE-against-the-sea) and **tense standoffs** (the
garrison seizure; Seth-Nakht's coercion). An audit of F7 finds **no swordfights / battles / duels** in the
approved story. Therefore Phase 2 is executed honestly as: **sharpen the legibility, tactics, physical stakes and
consequence of the EXISTING action beats** — NOT by inventing combat (which would change the film's nature and
violate the "no arc/plot/ending change, no gratuitous violence" rule). Each "defect" below is a real craft gap in
an existing beat, with a concrete, in-story fix.

## Principles applied (campaign §2.3–2.4)
Terrain geography · tactical objective (hold the line / break the charge) · feint + anticipation · physical
imbalance, fatigue, injury, consequence · reversal · emotional shift — expressed as **filmable visual steps**
(positions, actions/reactions, framing changes, rhythm, sound, inter-shot continuity). **No impossible moves, no
spatial incoherence, no repetition, no gratuitous gore.** Arcs, plot logic, and ending UNCHANGED.
