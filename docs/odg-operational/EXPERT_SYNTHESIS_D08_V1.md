## 4. ODG D08 synthesis — one coherent capability ("honest, fail-closed AI-readiness assurance", not nine specialties)
**Principle:** `certificationStatus` always `NOT_CERTIFIED`; readiness ≠ certification ≠ capability claim; no new primitive. **Mapping (expert principle → ODG module, honest behavior preserved):** Gebru dataset-documentation → regulatory-assurance evidence intake (client-declared evidence never auto-"verified"; sourceId required); Mitchell model-documentation/disaggregation → ai-assurance-assessment/report (control never PASS without executed check + independent verifier); Buolamwini disaggregated bias audit → fairness-eval (NO_DATA unless independent+representative ≥30/group; code-only ⇒ NOT_APPLICABLE; never "bias-free"); Raji audit-infra/black-box-insufficiency → assessment verifier gate + ai-assurance-regression (tooling ≠ accountability; INSUFFICIENT_EVIDENCE first-class); Chowdhury adversarial/agentic eval → third-party-agent-gate (OWASP Agentic, fail-closed ADMIT|DENY|ESCALATE); Dignum requirement→verify→monitor → ai-act-role-classifier + obligations register (deny-by-default UNDETERMINED); Floridi governance grounding → regulatory-assurance source-cite-or-refuse; Doshi-Velez evaluation-rigor grading → assessment verdict taxonomy (proxy never promoted to proof); Narayanan reject-inflated-claims/leakage → excellence-policy anti-overclaim (vendor self-reported accuracy never accepted as evidence).
**Retain:** disaggregated evaluation; documentation-as-governance; audit-infra realism + "black-box insufficient"; evaluation-rigor taxonomy; leakage/claim-skepticism; requirement→verify→monitor; source-cited normative grounding; adversarial agentic eval. **Adapt:** Model Cards/Datasheets *shape* → ODG assurance-report w/ mandatory NOT_CERTIFIED footer + per-field evidence grade; bias-bounty protocol → a bounded reproducible adversarial-eval experiment (only where independent data exists). **Reject (non-goals, honestly):** issuing a certificate/accredited assurance opinion (Big-4/COFRAC lane — ODG routes to an accredited body, doesn't compete); claiming "bias-free"/"compliant"/"safe"; replicating a COMPL-AI-style 27-benchmark technical battery (ODG has no model-level benchmark battery); accepting vendor self-reported metrics as evidence.
**ODG improvements over baselines:** (1) fail-closed by construction — where a Model Card/datasheet can be blank/self-serving, ODG's assessment cannot return PASS without an executed check + independent verifier (missing data ⇒ NO_DATA/INSUFFICIENT_EVIDENCE); (2) source-cite-or-refuse (no obligation without registry sourceId; no normative text reproduced ⇒ zero copyright exposure); (3) deterministic + reproducible + multi-tenant-isolated + provenance-stamped (byte-identical reruns proven in O3); (4) explicit non-certification boundary in every output (turns Narayanan skepticism + Raji "tooling ≠ accountability" into a product invariant).
**Failure modes & safeguards:** over-claim (certified/compliant/bias-free) → NOT_CERTIFIED always + excellence-policy refuses superlatives + fairness never "bias-free"; fail-open green test → control never PASS without executed check + independent verifier, cannot-verify=FAIL; vendor self-report accepted → client-declared evidence never "verified" + Narayanan leakage lens at intake; stale regulatory dates → deferred to a maintained register, classifier principle-level deny-by-default; agentic/prompt-injection → third-party-agent-gate fail-closed OWASP Agentic; scope creep → assembler boundAuthority INTERSECTION + cannot_modify.
**Measurable acceptance criteria:** 0 outputs assert CERTIFIED/compliant/bias-free (regression-tested); every obligation line carries a registry sourceId, 0 normative-text reproductions; fairness-eval returns NO_DATA/NOT_APPLICABLE whenever independent representative labels (<30/group) absent (100%); byte-identical readiness-matrix reruns (O3: {PARTIAL:6,BLOCKED:1,GAP:1,NOT_ASSESSED:2}, 10/10 tests); every verdict carries an evidence grade (executed+independent | proxy | declared-unverified).
