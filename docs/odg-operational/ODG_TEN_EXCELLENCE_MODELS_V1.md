# ODG Ten Engineering Excellence Models (V1)

**CTO Master Campaign V2, Phase 4.** Date **2026-11-01**. Ten **original** profession excellence models, each a coherent operating model (not nine copies of one expert; not a vendor pitch). Each consolidates its panel's verified principles (Phase 3) into **principle → practice → ODG mechanism**, states an **honest maturity (R0–R5)**, and names its **evidence-integrity differentiator**. Re-maps the 11 historical `EXPERT_SYNTHESIS §4` synthesis models into ten (D08+D09 → P10). **No superiority/"world-class" claim; no profession asserted above its proven maturity; mechanisms cite only MERGED modules.** Maturity ladder: R0 concept · R1 identified/spec · R2 built-in-repo-synthetic · R3 reproducible-on-own-repo · R4 external-authorized-case · R5 reproducible-operational-with-references. **No profession is R4+ (€0 clients).**

## The ten models

### P1 — Reversible-Steps Modernization (R3)
**Thesis:** change legacy systems only behind a pinned behavioral net, in small reversible steps. **Principles (panel):** Feathers (pin actual behavior via seams), Fowler (small reversible refactors), Beck (red-green-refactor), Farley/Humble (always-releasable + measured path), Forsgren (construct-valid metrics). **Practice:** capture characterization baseline → seam → refactor → compare → ship. **ODG mechanism:** G-01 characterization-baseline (BEHAVIOR_PRESERVED/CHANGED, fail-closed NO_BASELINE), patch-executor (write-confined), build-recovery, CI gate. **Differentiator:** behavioral-not-correctness honesty — the baseline proves *behavior preserved*, never *bug-free*. **Maturity R3** (reproducible on own repo; no external modernization case).

### P2 — Governed Agentic Engineering (R3)
**Thesis:** autonomy is admissible only through a fail-closed authority gate with provenanced verdicts. **Principles:** Wooldridge (formal agent authority), Yao (Thought→Act→Observe must be governed), Liang (multi-metric reproducible eval), Ng (data before model), Li (benchmark rigor). **Practice:** every agent action → evaluate (ADMIT/DENY/ESCALATE) → execute under GovernedExecutor → stamp verdict provenance. **ODG mechanism:** third-party-agent-gate (OWASP Agentic Top-10, deny-by-default), agent-governance-harness, GovernedExecutor + authorizeExecution, G-02 charter-record (subject/method/ground-truth), G-07 misleading-case-corpus. **Differentiator:** honest false-success resistance — G-07 measured a real 0.25 k-eval gap and reported it. **Maturity R3**.

### P3 — Evidence-First Supply-Chain Security (R3)
**Thesis:** security claims are only as good as the machine-readable, tamper-evident provenance behind them. **Principles:** Springett (CycloneDX SBOM), Cappos (TUF/in-toto integrity), Lorenc (Sigstore/SLSA provenance), Fox (dependency security), Moussouris (ISO 29147/30111 disclosure), Schneier (threat modeling), Anderson *(HISTORICAL — evidence-economics)*. **Practice:** generate SBOM (CycloneDX) → license fail-closed → attest provenance → seal evidence bundle → export. **ODG mechanism:** sbom-audit-service, license-policy (SPDX fail-closed on unknown), supply-chain-attest (8 ecosystems, recursive), G-05 golden-path-evidence-bundle, G-08 evidence-pack-export, bubblewrap confinement of untrusted compilers. **Differentiator:** CRA-aligned machine-readable SBOM + keyless tamper-evidence; **ODG finds-not** (no vuln-finding — honest boundary, per Zalewski gap). **Maturity R3**.

### P4 — Guarantee-Named Data Engineering (R2–R3)
**Thesis:** name the data guarantee and its failure mode before building the pipeline; test quality declaratively. **Principles:** Kleppmann (name guarantees/failure modes first), Handy (dbt declarative co-located tests), Moses (freshness/volume/schema/distribution), Das (event-time/watermark/exactly-once), Stonebraker (schema/constraints/workload-fit), Zaharia (lineage reproducibility), Reis (lifecycle + quality undercurrent). **Practice:** declare assertion types → run against dataset → emit SARIF → gate. **ODG mechanism:** G-04 dataset-quality-assertions (dbt-style taxonomy + SARIF adapter), dataset-quality-service, independent-label-policy, fairness-eval (NO_DATA until labelled set). **Differentiator:** quality assertions as code with SARIF interop; fairness honestly NO_DATA without an independent dataset. **Maturity R2–R3** (synthetic fixtures reproducible; no external data case).

### P5 — Platform-as-Product, Evidence-Emitting (R1 — HONEST)
**Thesis:** a platform earns adoption by paved golden paths that *emit* governance evidence, built only to real cognitive-load demand. **Principles:** Skelton/Pais (platform-as-product, no over-build; cognitive-load), Hightower (reproducible scaffolding), Hykes (hermetic builds), Rice (supply-chain + confinement), Beda (per-action authz), Cockcroft (failure-mode discipline), Burns (control-plane loop). **Practice:** golden path → hermetic build → emit SBOM+confinement+health bundle. **ODG mechanism:** G-05 golden-path-evidence-bundle only. **Differentiator:** the golden path produces a *sealed evidence bundle*, not just a deploy. **Maturity R1 — DECLARED HONESTLY: ODG has NO complete IDP (O8 is spec-only); this is an advisory/evidence model, not a platform product.**

### P6 — Evidence-Gated Quality (R3)
**Thesis:** a result counts only when a deny-by-default oracle, resistant to misleading cases, says so. **Principles:** Bolton (the evidence line ≈ reality-gate), Adzic (executable machine-checkable criteria ≈ mechanical-acceptance), Hendrickson (adversarial/negative-control design), Kaner (no context-free success), Bach (charter/provenance discipline), Crispin/Gregory (coverage vocabulary). **Practice:** Gherkin spec → deny-by-default criteria → evaluate → reality-gate ladder → charter the verdict. **ODG mechanism:** reality-gate (NOT_VERIFIED→ACCEPTANCE_VERIFIED), mechanical-acceptance (REJECT>BLOCKED>UNKNOWN>ACCEPT), k-eval, G-03 executable-spec-intake, G-07 misleading-case-corpus, G-01. **Differentiator:** ODG's most-developed internal capability — evaluation that treats *cannot-verify as FAIL* (a portfolio-internal observation, not a market claim). **Maturity R3**.

### P7 — Budgeted, Observable Reliability (R2–R3)
**Thesis:** reliability is a written, budgeted, auditable contract measured on vendor-neutral evidence — not a dashboard. **Principles:** Murphy (availability as budget), Rensin (reliability as provider↔consumer contract), Beyer (write reliability claims down), Majors/Fong-Jones (high-cardinality questions, SLO-driven), Parker (OTel portable evidence), Gregg (USE/baseline-before-claim), Allspaw (blameless evidence-gated learning). **Practice:** define SLO + error budget → collect (survivorship-guarded) → PREPARE response (never auto-apply) → learn from incidents. **ODG mechanism:** slo-targets/collector/response (autoApply always false), G-06 dora-metrics (denominator-explicit, deploy-freq never inferred), incident-recurrence, checkpoint-engine, code-health-service (absent⇒UNKNOWN). **Differentiator:** PREPARE-not-APPLY + denominator-explicit DORA (no vanity metric). **Maturity R2–R3** (DORA keys null until a provenanced baseline — owner-gated).

### P8 — Contracted Integration Conformance (R2–R3)
**Thesis:** integrate through a neutral, versioned, standards-conformant contract with honest stage separation — not live point-to-point glue. **Principles:** Hohpe/Woolf (EIP messaging vocabulary), Vernon (DDD canonical model), Newman (Strangler-Fig, scope discipline — *not* iPaaS), Richardson (Saga/outbox = compensation ≈ honest stage separation), van der Aalst (conformance checking), Erl (contracted self-contained capability). **Practice:** neutral invoice/doc model (EN 16931) → round-trip conformance → governed workflow with explicit prepared≠sent≠signed≠cashed stages. **ODG mechanism:** einvoice-* (Factur-X/UBL/CII round-trip), commercial-pipeline (12-stage, no stage skipped), mission-*/campaign-controller. **Differentiator:** conformance-to-standard + honest commercial-stage separation (SENT only with provider proof). **Maturity R2–R3**.

### P9 — Prove-the-Number FinOps (R2–R3)
**Thesis:** every cost/unit-economics number must be provable from observed usage, never asserted. **Principles:** Quinn (prove-the-number posture), Peterson (unit-economics anchor), Storment (FinOps framework vocabulary), Advey (cost allocation), Crowley/Bormann (regulated governance control). **Practice:** extract observed usage → compute unit economics on a comparable basis → allocate → refuse un-provable numbers. **ODG mechanism:** unit-economics, economic-extractor, economic-unit, budget-ledger/budget-contract (ALLOCATOR primitive), cost-accounting. **Differentiator:** observed-usage integrity — ODG does NOT meet FOCUS (honest gap per Fuller); it proves the numbers it does emit. **Maturity R2–R3**.

### P10 — Source-Cited Regulatory Assurance, Non-Certifying (R2–R3)
**Thesis:** produce auditable compliance *evidence* with every claim source-cited or refused — and never claim certification. **Principles:** Veale (reviewable/auditable ADM), Raji (audit frameworks + infra), Mitchell/Gebru (machine-usable model/dataset docs), Doshi-Velez (interpretability/eval taxonomy), Wachter (auditing/reasonable-inferences), Edwards/Renda (AI-Act role → practice), Chowdhury (operational audit). **Practice:** classify AI-Act role → map clause→mechanism (mechanism≠satisfied) → assemble evidence pack → export OSCAL-interop → refuse any superlative/uncited claim. **ODG mechanism:** ai-act-role-classifier, iso-* clause matrices (DOCUMENTED≠APPROVED≠EXECUTED; 0 SATISFIED), regulatory-assurance (source-cite-or-refuse), compliance-evidence-pack, G-08 evidence-pack-export (oscalNative:false, rejects SATISFIED/COMPLIANT/PASS/CERT), excellence-policy (refuses superlatives). **Differentiator:** an evidence-first, non-certifying posture — ODG emits source-cited *evidence*, labels NOT_CERTIFIED, and refuses to overclaim (a deliberate contrast to "compliant"-labelled tooling, asserted about ODG's own behavior, not as a judgement of competitors). **Maturity R2–R3** (reproducible readiness matrices; no external audit case).
