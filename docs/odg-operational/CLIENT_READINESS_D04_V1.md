## A. Professional identity & scope
A **data-quality attestation service**: ingest a real dataset, measure per-dimension quality vs a declared schema, emit an evidence-graded provenance-sealed report — reporting `NO_DATA` honestly rather than a fabricated clean score. IN: fail-closed dataset-quality audits (completeness/validity/uniqueness/conformance), independent-label integrity checks, fairness screens, sha256+commit provenance, framed toward an AI go/no-go gate or AI-Act Art.10 / GDPR accountability file. OUT (NON_GOAL): no ETL/pipeline/transformation runtime, no warehouse/lakehouse, no catalog/stewardship, no live observability/lineage/alerting/anomaly, no multi-tenant SaaS. A point audit/attestation that complements (never replaces) dbt/Soda/Monte Carlo/Collibra.

## E. Discovery, intake & diagnostic process
Client supplies (read-only, no-egress): dataset (CSV/JSON/records), optional declared JSON schema (types + enum/min/max/pattern + `keyFields`), and for any ground-truth labels a provenance descriptor. Diagnostic: classify measurable vs `NO_DATA`; map checkable dimensions to the enumerable assertion taxonomy (§F) so coverage incl. declared GAPS is explicit; unknown declared types carry no validity constraint (honest); a malformed schema constraint is a HIGH finding, not silently trusted.

## F. Delivery methodology & technical architecture
(EXPERT_SYNTHESIS_D04 §4 → actual modules; mechanism ≠ satisfied ≠ certified.) Ingest&parse fail-closed → `dataset-quality-service::parseInput/parseCsv` (empty ⇒ `NO_DATA` null not 100; unparseable ⇒ `INVALID_INPUT`/`PARSE_ERROR`). Measure (weighted, null-aware) → `assessDataset` — completeness/validity/uniqueness/conformance; `{id,area,severity,detail,remediation,evidence}` findings. Schema/constraint integrity → `TYPE_CHECK` + `cellConforms` enum/min/max/pattern; malformed constraint ⇒ field excluded as HIGH (no partial trust); unknown type ⇒ no constraint. ReDoS input-bound (#324) → `REGEX_CELL_CAP=4096`; over-long cell NON-conforming before regex. Label-independence → `independent-label-policy` (deny-by-default; ODG must not certify its own ground truth; dev/validation disjoint). Fairness → `fairness-eval`. Tamper-evident evidence → `evidence-provenance` (sha256 keyless or keyed-HMAC; digest excludes its own provenance; git commit + tree-dirty; SLSA/in-toto/SSDF PS.3 *principle*; fail-closed `sourceAvailable:false`). **Wave-4 G-04 `dataset-quality-assertions`** — enumerable frozen dbt-style registry (required_not_missing/type_valid/unique/accepted_values/range_min_max/pattern_match = IMPLEMENTED) honestly declaring GAPS (freshness/distribution/volume/relationships = NOT_YET_IMPLEMENTED, never silently passed) + a fail-closed SARIF adapter reusing `sarif-report.toSarif` (non-ok ⇒ INVALID_INPUT). Additive/pure; no new primitive.
