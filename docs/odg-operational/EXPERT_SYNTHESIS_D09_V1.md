## 4. ODG D09 synthesis — one coherent capability (NOT nine specialties)
**The capability:** *a reproducible, fail-closed, source-cited composer of cross-regime regulatory evidence and gap dossiers — explicitly `NOT_CERTIFIED`.* Nine experts distilled into one operating model with four doctrines, each wired to a real module: **(a) source-cite-or-refuse** (Kuner anchoring; Wachter ex-ante justification) → regulatory-assurance (sourceId-or-REFUSE) + iso-27001-clause-matrix (no normative text reproduced ⇒ no copyright); **(b) mechanism ≠ satisfaction ≠ certification** (Hildebrandt "code ≠ compliance"; Nemitz anti-self-certification; Lynskey effective-vs-complete) → compliance-evidence-pack (NOT_ASSESSED never silent PASS) + excellence-policy + iso-operational-evidence (verdicts SATISFIED_VERIFIED/GAP/DECLARED_UNVERIFIED/NOT_APPLICABLE/NOT_ASSESSED; certificationStatus=NOT_CERTIFIED always); **(c) reviewability / cross-regime composition** (Veale Reviewable ADM; DLA-Piper market thesis) → compliance-evidence-pack (CRA+AI-Act composer: SBOM + in-toto ed25519 attestation + AI-Act logging/robustness; each record independently reconstructable); **(d) governance-by-design, honestly bounded** (Brown *Regulating Code*; Edwards "transparency ≠ remedy"; Renda evidence-based regulation) → excellence-policy anti-overclaim + external-dependency register (accredited-body/paywalled-text/fees HUMAN-GATED €0 default; AFNOR under COFRAC n°4-0001 recorded as route-to body).
**Retain:** source-anchoring (Kuner); reviewability-as-accountability (Veale); effective-vs-complete coverage honesty (Lynskey); evidence-based methodology + standards-mapping (Renda); governance-by-design framing (Brown). **Adapt:** Wachter ex-ante-justification → evidence-before-claim gating; Wachter CDD → optional fairness golden-set input (labelled, not a guarantee); Edwards transparency critique → emphasise process/evidence records over post-hoc explanation; Hildebrandt LPbD → controls-as-code must keep records contestable, not merely machine-checkable. **Reject (as design hazards, with the experts' own warnings as justification):** "code-execution = compliance" (Hildebrandt); self-/ethics-certification + superlative claims (Nemitz/Edwards → enforced by excellence-policy); any suggestion ODG issues certificates (all — NOT_CERTIFIED invariant).
**ODG improvements over pure scholarship:** source-cite-or-refuse mechanised not aspirational; cross-regime composition by construction answers the DLA-Piper "common controls/evidence across frameworks" thesis the scholars describe but don't tool; fail-closed defaults (NOT_ASSESSED/DECLARED_UNVERIFIED) convert honesty norms into enforced states; reproducible + provenance-stamped + multi-tenant-isolated + network-free (addresses Brown PET leanings + procurement trust).
**Failure modes & safeguards:** hallucinated/stale obligation → sourceId-or-REFUSE + owner-gated register currency; silent PASS on missing input → NOT_ASSESSED default; over-claim → excellence-policy superlative refusal + NOT_CERTIFIED invariant; client evidence trusted blindly → DECLARED_UNVERIFIED unless an injected independent verifier confirms; "code ran ⇒ control satisfied" (Hildebrandt hazard) → mechanism/satisfaction/certification states categorically distinct; cross-tenant leakage → multi-tenant isolation; regulatory flux → dates/obligations deferred to a per-engagement register.
**Measurable acceptance criteria:** 100% of emitted obligations carry a resolvable sourceId (0 uncited); 0 silent PASS; byte-identical dossier on re-run (determinism/provenance); certificationStatus==NOT_CERTIFIED in every output; excellence-policy rejects any superlative lacking a cited benchmark.
**Reproducible experiments:** (1) re-run CRA+AI-Act pack twice on O2/O3 fixtures (CycloneDX 489-comp SBOM + AI-Act readiness) → byte-identical + ed25519 attestation verifies; (2) obligation w/ no registry sourceId → REFUSED/dropped; (3) unverified client evidence + no independent verifier → DECLARED_UNVERIFIED (never SATISFIED_VERIFIED); (4) omit AI-Act input → NOT_ASSESSED for AI-Act themes (not silent PASS); (5) "best-in-class compliant" draft → excellence-policy rejects.
