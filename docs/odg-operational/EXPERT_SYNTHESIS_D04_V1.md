## 4. ODG D04 synthesis — one coherent capability (not nine specialties)
**Thesis:** an honest, fail-closed, reproducible, tamper-evident **data-quality + provenance attestation for AI-ready datasets** — point-in-time measurement + evidence, explicitly NOT ETL/orchestration/live-observability/catalog. **Adopt:** (1) declarative check taxonomy (Handy/dbt + Moses dimensions) — ODG has completeness/validity/uniqueness/conformance; adopt dbt-style *named enumerable assertion types* + Moses's freshness/distribution as candidate future dimensions (marked NOT_YET_IMPLEMENTED); (2) lineage/derivation binding (Zaharia/Das) → evidence-provenance (sha256+commit): bind every metric to exact input bytes + schema + commit; (3) idempotent determinism (Beauchemin) → ODG's pure/no-fs/no-network/no-clock service = the reproducibility guarantee, preserve absolutely; (4) schema/constraint rigor (Stonebraker) → TYPE_CHECK + enum/min/max/pattern; "unknown declared type ⇒ no constraint (honest)"; (5) honest scoping (Reis/Kleppmann) → quality is an undercurrent attested at the transform→serving / AI-go/no-go boundary under stated assumptions.
**Conflicts & resolution:** gate-that-can-pass (dbt/GX) vs fail-closed attestation → **ODG resolves fail-closed** (empty ⇒ NO_DATA not fabricated 100; malformed regex schema ⇒ HIGH error excluded from conformance, never silently passed); live observability (Moses) vs point-in-time audit → ODG does NOT claim continuous monitoring, attests a snapshot (honest boundary); self-grading risk → independent-label-policy deny-by-default (ODG must not certify its own ground truth — the exactly-once integrity instinct applied to labels).
**Retain:** fail-closed semantics, purity/determinism, per-issue {id,area,severity,detail,remediation,evidence} findings, sha256+commit provenance, independent-label gate, ReDoS input-bound. **Adapt:** enumerable named assertion types (dbt), dimension vocab (Moses) as optional schema-declared honestly-labelled extensions; SARIF emission. **Reject (out of scope by design):** orchestration/scheduling (Airflow), transformation runtime (dbt/Spark), live anomaly monitoring/alerting/lineage SaaS (Monte Carlo), catalog/stewardship. ODG is not a platform.
**Reference architecture (real modules):** ingest&parse (fail-closed) → `dataset-quality-service::parseInput/parseCsv`; measure (weighted null-aware overall) → `assessDataset`; schema/constraint integrity (type+enum/min/max/pattern; malformed=HIGH, excluded) → TYPE_CHECK/cellConforms/malformedConstraints; label-independence → `independent-label-policy::assessLabelIndependence`; fairness screen → `fairness-eval`; tamper-evident evidence → `evidence-provenance`; SQL constraint checker.
**Failure modes & safeguards:** green-that-lies → fail-closed NO_DATA/INVALID_INPUT, overall never fabricated; schema trust on broken constraint → malformed regex=HIGH finding, field excluded; ReDoS over N rows → REGEX_CELL_CAP=4096, over-cap=non-conforming before regex; self-certified ground truth → independent-label deny-by-default; order-sensitive dedup → documented limit + keyFields; semantic/business-correctness overclaim → explicit limit ("data-quality assessment, NOT semantic/business-correctness validation").
**Measurable criteria:** deterministic re-run bit-identical metrics on identical input+commit; NO_DATA on empty (never 100); malformed-constraint ⇒ HIGH+excluded; over-cap cell ⇒ non-conforming; independence gate rejects self-authored provenance; every attestation carries input-hash + commit.

## 5. Benchmark/eval spec
Goal: measure ODG's DQ *measurement correctness, honesty, reproducibility* — NOT superiority. Tasks: (1) tabular profiling on labelled public datasets (UCI Adult / NYC Taxi samples) with known injected defects → recover exact per-dimension counts; (2) schema-conformance with declared JSON schema incl. deliberately malformed constraints; (3) fail-closed battery (empty/truncated/non-UTF8/non-object rows/unknown format); (4) ReDoS robustness (pathological regex + >4096-char cells); (5) label-independence (self vs third-party provenance, missing sourceRef, dev/val overlap). External baselines (comparison, not ranking): **Great Expectations**, **Soda** (SodaCL), **dbt tests**, optionally pandas/Arrow profiling — compare *behavior on the same injected-defect fixtures*, especially divergence on empty/ambiguous inputs (ODG NO_DATA vs tools' configurable pass). Metrics: defect-detection precision/recall vs ground truth; false-pass rate on empty/invalid (ODG target 0); determinism across runs/hosts; schema-error surfacing; ReDoS-bounded worst-case latency; independence-gate confusion matrix. Limitations up front: no live-monitoring/lineage/anomaly-over-time benchmarks (out of scope); baselines are configurable so a "pass" comparison is apples-to-oranges — report *behavioral differences* not a leaderboard; broad-IT needs an external labelled eval set (NO_DATA until admitted); no superiority claim without reproduced independently-sourced evidence.
