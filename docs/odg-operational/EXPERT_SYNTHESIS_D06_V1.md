## 4. ODG D06 synthesis — one coherent capability (mapped to ODG's REAL disciplines)
**Honesty gate (restated):** ODG is NOT an IDP (no cloud deploy / K8s control plane / portal / self-service golden-path product; O8=SPEC-ONLY; host=private VPS off-limits). The D06 offer is **advisory/spec/evidence**, not a platform. No 10th primitive.
**The coherent single capability:** "Governed, hermetic, evidence-emitting build substrate + golden-path advisory" = (1) hermetic reproducibility (Hykes+Hightower → hermetic test harness + governed build); (2) declarative authority-bounded control (Burns+Beda → GovernedExecutor, campaign-controller, authorizeExecution/evaluateAgentAction); (3) supply-chain evidence (Rice → O2 CycloneDX SBOM + provenance + confinement posture); (4) observability + resilience discipline (Cockcroft → odg-health + "cannot verify"=FAIL + adversarial verification); (5) advisory framing (Skelton+Pais → golden-path *readiness assessment* + TVP guidance, explicitly warning against building the platform ODG lacks); (6) IaC-method-not-capability (Hashimoto → declarative scaffolding w/ "ODG provisions no infrastructure" disclaimer).
**Retain (direct, real):** Hykes hermetic local=CI; Rice isolation + supply-chain evidence; Beda per-action authz/agent-governance; Cockcroft observability + failure-injection; Skelton/Pais TVP + cognitive-load + "don't over-build". **Adapt (method only):** Hashimoto IaC + Burns/Hightower declarative control-loop → applied to mission-contract-factory scaffolding, NOT infra provisioning. **Reject (would be a false claim):** cloud/K8s provisioning, multi-tenant control plane, portal/catalog/plugin ecosystem, eBPF/kernel runtime security, SecNumCloud/sovereignty-as-ODG-property, chaos-in-production against real workloads.
**ODG improvements (within existing primitives):** make the governed build emit a per-run **evidence bundle** (SBOM + provenance + confinement attestation + health snapshot) as a first-class golden-path *reference* artifact (reuses O2 + health); package a read-only **golden-path readiness assessment** method artifact (Skelton/Pais); strengthen fail-closed agent-action evaluation citing Beda/SPIFFE as the external reference.
**Failure modes & safeguards:** over-claiming "ODG is an IDP" → honesty header in every deliverable + TVP doctrinal brake; evidence over-reach (SBOM ≠ conformity) → O2 doctrine (preparation ≠ CRA/ISO conformity; mechanism ≠ satisfied ≠ certified); green build mistaken for proof → "cannot verify"=FAIL; authority escalation via composed experts → §307 INTERSECTION + cannot_modify; concurrent dist-mutating audit vs regression → read-only or serialize; vendor-sourced external claims → confidence labels + FACT-vs-INFERENCE.
**Measurable criteria (no superiority claim):** reproducibility (identical build/test verdict across ≥N isolated runs); evidence completeness (% golden-path reference runs emitting SBOM+provenance+health); fail-closed rate (% unauthorized/unverifiable actions BLOCKED, target 100%); advisory fidelity (recommendations traceable to a cited Team-Topologies/DORA principle).
**Reproducible experiments:** (1) hermetic parity (same mission contract in bwrap vs CI → identical verdict + evidence hash); (2) confinement escape probe (host-read from a confined compiler → BLOCK); (3) agent-governance fail-closed (unauthorized action → DENY/ESCALATE); (4) evidence-bundle emission (golden-path reference → CycloneDX SBOM + provenance + odg-health snapshot, internally consistent); (5) failure-injection on verification (force a verify-step failure → gate reds, no fail-open).
