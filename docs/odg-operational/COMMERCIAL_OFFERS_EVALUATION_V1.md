## Selected to TEST first (evidence-based)
**A (technical audit) + C (technical assurance)** — ODG's **strongest proven, gated** capabilities, high margin, fast
delivery, easiest first reference; align with the AI-governance narrative (readiness evidence). **D (recurring)** layered
on A/C once a reference exists (recurring pricing is real in-market). **B** selectively; **E** prepared but partner-gated;
**F** watch-only (solo eligibility barrier).

## Per-offer rigour (A + C, the anchors)
Each must specify, before any send: buyer, problem, deliverable, **scope + exclusions**, measurable **acceptance
criteria**, realistic delay, **price justified** (HYP), costs, risks, **capability proof** (gated suite / artefact),
any warranty (obligation de **moyens**, not de résultat), payment terms, next commercial step. Generate via
`proposal-generator` (fail-closed anti-overclaim) → register via `commercial-pipeline` (evidence-gated).

## Honesty
No offer claims certification, guaranteed compliance, or a proven client outcome. Capability labels (STRONG/PARTIAL/
LEVERAGE) reflect **gated code evidence**, not delivered client engagements (0 to date). Prices unvalidated.
