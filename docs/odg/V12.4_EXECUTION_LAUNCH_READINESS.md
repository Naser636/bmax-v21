- **Per-lot close (mandatory):** evidence → tests run → independent verification → local commit (if authorized) →
  register status → matrix status → compass REPRISE → select next.
- **After interruption:** re-read compass + matrix + register → Truth Lock the real repo → resume at the last PROVEN
  lot → never re-run an ACCEPTED lot (campaign-controller NO-REPEAT already enforces this).
- **Interruption behaviours:** context/session/timeout/compile-fail/test-fail/resource/component/authorization/
  voluntary-stop → each leaves a recoverable state; an incomplete lot is NEVER marked ACCEPTED (fail-closed).
- **Continuation:** within the already-authorized local perimeter with satisfied prereqs, ODG selects the next lot
  WITHOUT a new human decision; owner-gated decisions stay reserved.
